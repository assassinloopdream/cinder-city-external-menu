## 🧩 About

**Cinder City Companion** is a curated list of Cinder City open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap reader, HUD widgets
- **Quality-of-Life Helpers** — inventory notes, loot catalog, config presets
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Overlay Menu — toggle a compact external menu on top of the game
- Minimap Reader — track nearby points of interest on a map layer
- Loot Notes — catalog items and resources in the current run
- Speed Presets — adjust editor and playback settings for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse gear, colors, and cosmetic notes
- Custom Loadout Notes — organize player presets
- HUD Widgets — improved visibility of on-screen information

### Aimbot
- Practice Notes — segment study on any layout
- Config Presets — switch between conservative profiles
- Input Helper Notes — chain complex maneuvers in the editor
